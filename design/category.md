# category — 카테고리별 글

## 한눈에

| | |
| --- | --- |
| URL | `/[lang]/category/<id>/` — `systems` · `scaling` · `reliability` · `devops` 중 **글이 있는 것만** 만들어진다 |
| 소스 | `src/pages/[lang]/category/[category].astro` |
| 컴포넌트 | 홈과 같다: `ProfileHero` → `ArticleBrowser category={id}` → `BackToTop` |
| 헤더 현재 메뉴 | 홈 |
| 검색 노출 | ✓ |
| 페이지 제목 | "Systems · Jieun" / 설명 "Jieun — Systems" |

## 이 페이지가 하는 일

한 분야의 글만 모아 보는 곳. 글 상세의 카테고리 칩, 목록의 카테고리 칩, 홈의 칩 줄에서 들어온다.
카테고리 URL 자체를 공유할 수 있게 **별도 페이지**로 둔다.

## 화면 구조

**홈과 같은 화면**이다. 다른 곳은 두 군데뿐이다.

```plaintext
┌ Header ─────────────────────────────── (현재 메뉴: 홈) ┐
├ Hero — 홈과 같음 (프로필 그림 · 이름 · 모토 · 링크 아이콘) ┤
├────────────────────────────────────────────────────────┤
│ [전체 20] [█SYSTEMS 10█] [RELIABILITY 6] …             │  ① 이 카테고리 칩이 초록 면
│                                                        │
│ SYSTEMS — ARTICLES                                     │  ② 라벨이 "<카테고리> — Articles/글"
│ ┌──────────┐  제목                                     │
│ │  커버    │  메타                                      │
│ └──────────┘  요약 · [SYSTEMS]                          │
│ …  (이 카테고리 글만, 8개씩)                             │
├ Footer ────────────────────────────────────────────────┤
```

모바일·태블릿 모양도 홈과 같다 → [`home.md`](./home.md#반응형).

## 구성 요소

| 요소 | 홈과 다른 점 |
| --- | --- |
| `<h1>` (숨김) | 사이트 이름 대신 **카테고리 이름** ("Systems") |
| 칩 줄 | 이 카테고리 칩이 선택 상태(`aria-current="page"`). "전체" 칩은 홈(`/[lang]/`)으로 간다 |
| 목록 라벨 | "Systems — Articles" / "Systems — 글" (`.eyebrow` 가 대문자로 올린다) |
| 목록 | 이 카테고리 글만. 8개씩 "더 보기" |

## 다크 모드 · 한/영 차이

홈과 같다. 카테고리 이름은 두 언어 모두 영어("Systems"), 라벨 뒤 "Articles / 글"만 바뀐다.

## 규칙

- 🔴 **홈과 다른 화면을 만들지 않는다.** 카테고리 설명 문단·다른 히어로·다른 목록 모양을 넣으면 홈↔카테고리를 오갈 때 화면이 튄다. 칩 상태와 라벨만 다르다.
- 🔴 카테고리 목록은 `src/i18n/ui.ts` 의 `categories` 와 `src/content.config.ts` 의 `category` enum 이 **같은 id** 를 써야 한다. 새 카테고리는 두 곳에 같이 넣는다.
- 글이 0개인 카테고리는 페이지도 칩도 만들지 않는다 (`categoryStats` 가 거른다).

## 알아둘 것

- 칩 순서는 글 수 많은 순이라, 글이 늘면 칩 순서가 바뀔 수 있다. 고정 순서가 필요하면 `categoryStats` 정렬을 바꾼다.
