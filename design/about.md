## 이 페이지가 하는 일

**채용 담당자**가 "이 사람 누구지?" 할 때 오는 곳. 링크드인·글 사이드바에서 들어온다.
긴 이력 대신 **사진 · 인사 · 네 문장 · 연락 아이콘**만 둔다. 자세한 건 글이 말해준다.

## 구성 요소

### 점 바탕

- 홈 히어로와 같은 에버그린 점(`Particles`)을 카드 뒤 전체에 깐다. 면은 히어로와 같은 `--bg → --bg-2` 세로 그라데이션.
- `.field` 가 헤더 높이만큼 위로 올라가고(`data-under-header`) 헤더가 투명해진다 — 홈처럼 점이 메뉴 뒤에서도 떠다닌다.
- 카드 면이 `--bg` 로 꽉 차 있어 점은 **카드 바깥 여백에만** 보인다.
- 면적이 히어로 띠보다 훨씬 넓어 점 상한을 200 으로 올렸다(`max={200}`). 밀도(면적/7000)는 홈 히어로와 같다.

### 카드

- 2단 그리드 `0.92fr : 1.08fr`, 세로 가운데 정렬, 간격 56px, 안쪽 44px.
- `--border` 1px + `--radius-lg`, 면 `--bg`. **그림자 없음.**

### 프로필 그림

- **홈 히어로와 같은 그림**이다. 크게 보이므로 고해상도판 `avatarLargeSrc`(`/avatar-illustration-1024.jpg`)를 쓴다.
  - 원본 336px 를 Real-ESRGAN anime 모델로 4배 키운 뒤 1024px 로 줄인 것(`src/i18n/ui.ts` 주석).
- 정사각형, `--radius`, `--hairline` 테두리, 그림이 뜨기 전엔 `--surface` 면.

### 글

| 요소 | 모양 |
| --- | --- |
| 인사 `<h1>` | `clamp(28px, 3.4vw, 38px)` / **900**, 줄간격 1.25, 자간 -0.025em, `text-wrap: balance` |
| 소개 | 위 22px, 17px, 줄간격 1.9, `--text-subtle`, 최대 34em, **어절 단위 줄바꿈**(`word-break: keep-all`) |
| 링크 아이콘 | 위 28px, `SocialLinks muted` (GitHub · LinkedIn · 메일, 복사 알림은 아래 왼쪽). 원 안쪽 여백만큼 왼쪽으로 6px 당겨 글줄에 맞춘다 |

### 들어올 때 움직임

**홈 히어로와 같은 말투의 GSAP 타임라인**(공용 값은 `src/lib/motion.ts`, foundations.md "움직임").

| 시작 | 무엇 | 값 |
| --- | --- | --- |
| 0s | 뒤 점이 번짐 | 1.6s `power1.out` (`DOTS`) |
| 0s | 카드가 떠오름 | 아래 24px, 0.8s `power3.out` |
| 0.1s | 그림이 튀어오름 | scale 0.92 → 1, `back.out(1.4)` 0.9s |
| 0.25s | 인사 단어가 하나씩 떠오름 | 아래 24px, 0.07s 간격 |
| 이어서 | 소개 문단 → 링크 아이콘 | 아래 16px, 0.1s 간격, 인사가 끝나기 0.55s 전부터 |

- 인사는 공백으로 단어를 나눠 `<span>` 으로 감싼다. 단어 사이 공백은 그대로 남겨 복사·줄바꿈이 원문과 같다.
- 카드 한 장이 첫 화면에 다 들어와서 스크롤 연동(ScrollTrigger) 없이 들어올 때 한 번이면 된다.
- 뜨기 전엔 `.field > *`(점 · 카드)를 숨겨 둔다. 모션 줄이기면 아무것도 하지 않는다 — foundations.md 공용 약속.

## 다크 모드

토큰만 바뀐다. 카드 선은 `--border`(다크 `#27272a`), 소개 글은 `--text-subtle`(다크 `#a1a1aa`).

## 한/영 차이

인사·소개·alt 문구만 다르다 (위 표). 레이아웃은 같다.

## 규칙

- 🔴 **회사명·연차·직함을 쓰지 않는다.** (2026-09 결정)
- 🔴 소개 문장은 **전 회사 지칭 규칙**을 따른다 — 과거형, 전 회사 제품을 "우리 X"로 부르지 않는다 (CLAUDE.md).
- 🔴 프로필 그림은 **홈 히어로와 같은 그림**이다. `avatarSrc` 를 바꾸면 `avatarLargeSrc` 도 같은 그림의 큰 판으로 바꾼다.
- 이력서·이메일 **버튼을 두지 않는다.** 연락은 아이콘 줄로 충분하다 (결정 이력 참고).
- 소개 문단은 네 문장 안팎으로 짧게. 늘리고 싶으면 글을 쓰고 글로 보낸다.

## 알아둘 것 — 결정 이력 (2026-09-19)

1. **v1 "글 지도"안 — 버림.** 히어로 + 소개 + 4단계 파이프라인(숫자) + 구조 결정 6개 + 프로젝트 카드 4장 + 일하는 방식 + 기술 + 연락. 채용 담당자용으로 짰지만 너무 길었다.
2. **v2 카드안 — 채택.** 참고 이미지(사진 왼쪽 · 인사 · 문단 · 버튼 · 아이콘) 구조. 버튼은 분홍 그라데이션 대신 사이트 초록.
3. **v3** — 이름을 "정지은"으로, 그림을 실사에서 홈과 같은 일러스트로.
4. **적용 시** — "이력서 보기 / 이메일" 버튼을 빼고 홈 히어로와 같은 회색 아이콘 줄로 바꿨다. 그림은 업스케일판으로.
5. **점 바탕** — 메뉴(홈·소개·태그)를 오갈 때 히어로가 들쭉날쭉해서, 카드 뒤에도 홈과 같은 점을 깔고 헤더 뒤까지 올렸다.
   사진은 카드에 이미 크게 있으니 히어로를 따로 두지 않는다 ([`shell.md`](./shell.md#어느-페이지가-무엇을-쓰나)).

### 남은 숙제

- **모바일에선 점이 거의 안 보인다.** 카드가 화면 폭을 거의 다 채워 좌우 16px 틈에만 점이 걸린다. 카드 좌우 여백을 늘릴지 정해야 한다.
