# foundations — 토큰과 기본 규칙

모든 페이지의 바탕. 값의 원본은 `src/styles/global.css`의 `:root` 다.

## 톤 한 줄

**흰 지면 + 징크(zinc) 회색 단계 + 상록(에버그린) 초록 포인트 하나.**
면을 그림자로 띄우지 않고 **얇은 선(`--border`)과 여백**으로 나눈다. 콘텐츠 폭은 1040px.

## 레이아웃

- **콘텐츠 폭** `--width-page: 1040px` (글 상세 본문이 약 700px, 한 줄 40자 안팎이 되는 폭), **좌우 여백** `--gutter: 16px`.
- **헤더 높이** `--header-h`: 100px (≥1072) · 80px · 60px (≤809). 헤더와, 헤더 뒤로 올라가는 히어로(`Hero snug` — 홈·카테고리·태그)·소개 점 바탕이 같이 쓴다.
- 모든 폭 제한은 공용 클래스 **`.frame`** 으로 한다 (`max-width: 1040 + 16×2`, 가운데 정렬, 좌우 16px).
- 형제 요소 간격은 `gap` 으로 준다.

### 반경

| 토큰 | 값 | 쓰임 |
| --- | --- | --- |
| `--radius-sm` | 8px | 카테고리 칩(`.chip`), 작은 썸네일, 검색 결과 줄 |
| `--radius` | 12px | 이미지, 인용·콜아웃, 코드 블록 |
| `--radius-lg` | 16px | 카드(소개·시리즈·다음 글), 검색창 |
| `999px` | 알약 | 태그, 필터 칩, 아이콘 버튼, 아바타 |

### 화면 폭 기준

| 이름 | 폭 | CSS |
| --- | --- | --- |
| 데스크톱 | 1072px 이상 | (기본) |
| 태블릿 | 810–1071px | `@media (max-width: 1071px)` |
| 모바일 | 809px 이하 | `@media (max-width: 809px)` |

새 기준을 만들지 않는다. 컴포넌트마다 이 두 값만 쓴다.
태블릿 기준점은 **콘텐츠 폭 + 좌우 여백**(1040 + 16×2 = 1072)에 맞춘다. 콘텐츠 폭을 바꾸면 이 값과 `PostLayout` 의 `matchMedia('(min-width: 1072px)')` 도 같이 바꾼다.

| 어디 | 무엇 | 값 |
| --- | --- | --- |
| hover 색·면 | 색 전환 | `0.15s` |
| 헤더 메뉴 | 밑줄이 가운데서 펼쳐짐 | `0.25s cubic-bezier(0.44, 0, 0.56, 1)` |
| 히어로 | **GSAP** — 점이 번지고, 사진(구슬)이 튀어오르고, 이름 → 제목 단어(0.07s 간격) → 링크 아이콘이 떠오름 | `Hero.astro`, [`shell.md`](./shell.md#히어로--srccomponentsheroastro) |
| 소개 카드 | **GSAP** — 히어로와 같은 말투. 점 · 카드 → 그림 튀어오름 → 인사 단어 → 소개 → 아이콘 | `about.astro`, [`about.md`](./about.md#들어올-때-움직임) |

| 목록 이미지 | 기본 cover만 hover 시 살짝 확대, contain은 확대하지 않음 | `scale(1.03)`, `0.4s` |
| 히어로 점 | 천천히 떠다님, 화면 밖이면 멈춤 | `Particles.astro` 스크립트 (히어로·소개 카드 뒤) |

`prefers-reduced-motion: reduce` 면 **전역에서** 애니메이션·전환을 끈다(`global.css` 끝). GSAP 모션도 돌지 않는다(아래). 파티클은 한 번만 그린다.

### 들어올 때 모션 — GSAP 공용 약속 (`src/lib/motion.ts`)

첫 화면 모션은 전부 **GSAP** 이다(CSS 키프레임은 쓰지 않는다). 한 페이지에서 첫 화면을 맡는 곳은 하나다 — 히어로 · 소개 카드 · 글 머리말.

- **값**: 아래에서 떠오름 `power3.out` 0.8s(`ENTER_DEFAULTS`), 사진·구슬은 튀어오름 `back.out(1.6)` scale 0.85(`POP`), 점은 1.6s 동안 번짐(`DOTS`).
- **번쩍임 방지**: GSAP 은 페이지를 그린 뒤에 뜬다. `BaseHead.astro` 인라인 스크립트가 먼저 `html.gsap-enter` 를 붙이고,
  각 컴포넌트 CSS 가 그걸 보고 **첫 화면 덩어리**(히어로 `.hero > *`, 소개 `.field > *`, 글 `.post-wrap`)를 숨긴다.
  페이지 스크립트는 `enterTimeline()` 으로 클래스를 떼고 **같은 틱에** from 상태를 입힌다 — 그래서 사이에 비치지 않는다.
- **대비책**: 스크립트가 끝내 못 뜨면 2.5초 뒤 클래스를 떼서 그냥 보여준다.
- **끝나면** `clearProps` 로 인라인 `opacity`·`transform` 을 지운다 — 남은 transform 이 고정 위치 요소의 기준을 바꾸지 않게.
- **모션 줄이기**면 클래스를 붙이지 않고, `enterTimeline()` 이 `null` 을 돌려줘 아무것도 하지 않는다.
- 새 페이지에 첫 화면 모션을 넣으려면: 첫 화면 덩어리에 `:global(html.gsap-enter) … { opacity: 0 }` 를 걸고, 스크립트에서 `enterTimeline()` 을 받아 `from` 을 건다.

## 화면 색상

흰 배경 한 가지를 사용한다. 자동 테마 선택·저장값·전환 버튼은 제거했다. 코드 블록은 `github-light`, 댓글은 `/giscus/light.css`로 고정한다. 모바일 주소창 색은 `#ffffff`이다.

프로필 배너는 `--profile-banner-bg: #e9edf1`로 목록의 흰 지면과 구분한다. 원본이 어두운 커버의 `coverBackground: dark`는 이미지 여백 지정이며 화면 테마와 별개다.

NCP 운영 계정 이전 시리즈의 표는 `.prose[data-series='ncp-account-migration']` 안에서만 파랑·초록·보라의 옅은 열 배경을 사용한다. 첫째 열은 `--table-bg`/`--table-head`, 둘째는 `--table-bg-secondary`/`--table-head-secondary`, 셋째는 `--table-bg-tertiary`/`--table-head-tertiary`다. 기본 표는 무채색을 유지한다. 배경은 셀에만 칠하고 스크롤 영역은 투명하게 둔다.

## 규칙

- 🔴 **색은 토큰으로만 쓴다.** 새 hex 를 컴포넌트에 직접 쓰지 않는다. 예외는 넷뿐이고, 모두 위 단계표 안의 값이다:
  콜아웃 의미 색, 히어로 점 `--dot-*`, 404 구슬 `--orb-*`, SNS 카드 템플릿(`scripts/og-card.html`, 브라우저 밖에서 렌더링돼 토큰을 못 읽는다).
- 🔴 **사이트 UI의 포인트 색은 에버그린 하나.** 본문의 비교 표·도식은 `post.md`에 정의한 제한된 자료용 팔레트를 사용한다. 자료 색상을 메뉴·버튼의 새 브랜드 색상으로 확장하지 않는다.
- 사이트는 밝은 화면으로 고정한다. 자동 테마 분기와 전환 버튼을 다시 추가하지 않는다.
- 면은 그림자 대신 `--border` 선과 여백으로 나눈다.
- SNS 공유 카드의 어두운 팔레트는 웹페이지 테마와 별개다. 공유 카드 디자인을 바꿀 때 `scripts/og-card.html`을 함께 확인한다.
