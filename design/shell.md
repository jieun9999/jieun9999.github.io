# shell — 여러 페이지가 같이 쓰는 틀

페이지가 아니라, 페이지들을 감싸거나 여러 페이지에 들어가는 부분이다.
토큰은 [`foundations.md`](./foundations.md) 참고.

## 페이지 뼈대 — `src/layouts/BaseLayout.astro`

모든 페이지가 이 순서로 그려진다.

```plaintext
BaseHead   메타·폰트·테마 결정 스크립트 (화면엔 안 보임)

```

## 헤더 — `src/components/Header.astro`

```plaintext
데스크톱 (80px)
┌────────────────────────────────────────────────────────────────┐
│ Jieun                  홈   소개   태그              🔍  EN  ☾ │
│                             ‾‾‾‾                               │
└────────────────────────────────────────────────────────────────┘
  1fr (왼쪽 정렬)          auto (가운데)           1fr (오른쪽 정렬)

모바일 (60px, ≤809)
┌──────────────────────────────────┐
│ Jieun                    🔍 ☾ ☰ │
└──────────────────────────────────┘
```

- **로고**: 워드마크 하나(`BrandWordmark.astro`) — "Jieun" 28px(모바일 24px)/900. 아이콘은 따로 두지 않는다.
  - J 는 파비콘과 같은 기하 J(줄기 + 1/4원 + 반원)에 잎맥선 6개를 그은 SVG. 다크에선 파비콘 그대로(민트 J + 초록 잎맥),
    라이트에선 민트가 흰 바탕에 묻히므로 뒤집어서(에버그린 J + 민트 잎맥) 그린다.
  - "ieun" 은 진짜 텍스트에 에버그린 세로 그라데이션을 `background-clip: text` 로 입힌다. 가운데 스톱이 `--accent`.
  - 화면엔 J 가 그림이라 스크린리더용으로 `sr-only` "Jieun" 을 따로 둔다.
  - 파비콘(`public/favicon.svg`, 같은 그림으로 `favicon.ico`·`favicon-96x96.png`)은 에버그린 타일 + 민트 J + 초록 잎맥.
    `apple-touch-icon`·`web-app-manifest-*` 는 아직 예전 나무 그림이다(OG 카드가 512 를 로고로 쓴다).
- **메뉴**: 홈 · 소개 · 태그, 16px/600, 간격 16px.
  - 현재 메뉴는 **초록 글자 + 2px 초록 밑줄**(글자 아래 6px). 글자색만으론 검정과 구분이 잘 안 돼서 밑줄을 넣었다.
  - hover 하면 같은 밑줄이 가운데서 펼쳐진다.
  - "홈"은 `/[lang]/`, `/category/…`, `/blog/…` 에서 모두 현재 메뉴다. "태그"는 `/tags/` 와 `/tag/…` 둘 다.
- **도구**: 검색 · 언어 · 테마 순. 모두 `.icon-btn` — 32px 원, 면은 `--surface-2` 70%.
  - 언어 버튼은 **다른 언어의 코드**를 보여준다 (한국어 페이지면 `EN`). 번역이 있으면 번역 글로, 없으면 그 언어 홈으로 간다.
  - 테마 버튼은 라이트에서 달, 다크에서 해를 보여준다.
- **위치**: 데스크톱에서는 스크롤과 함께 올라가고, **1199px 이하에서는 위에 붙는다**(sticky).
- **모바일(≤809)**: 메뉴와 언어 버튼이 사라지고 햄버거(☰)가 생긴다.
  - 햄버거를 누르면 헤더 아래가 전부 메뉴 패널로 덮인다. 링크가 세로로 서고, 선 아래 "View in English" / "한국어로 보기" 글자 링크.
  - 열리면 본문 스크롤이 잠긴다. Esc 로 닫히고, 링크를 누르거나 창이 810px 이상으로 넓어지면 닫힌다.

## 검색창 — `src/components/SearchDialog.astro`

헤더 돋보기가 여는 `<dialog>`.

```plaintext
┌──────────────────────────────────────────────┐  560px, 위에서 12vh
│ 🔍  글 검색…                           [Esc] │
├──────────────────────────────────────────────┤  ← 입력 전엔 여기까지만
│ 키워드 발굴 25초를 0.2초로 — …        15/800 │
│ Systems · 2026년 8월 10일            13/600  │
│ …                                            │
└──────────────────────────────────────────────┘
뒤 배경: rgba(9,9,11,.35) + blur 4px
```

- 서버가 없으니 `/[lang]/search.json` 을 받아 브라우저에서 제목·요약·태그·카테고리를 거른다. 결과는 최대 20개.
- **입력하기 전에는 입력칸만** 보인다. 결과가 없으면 "맞는 글이 없어요." / "No matching posts."
- 결과 한 줄은 제목(15px/800) + "카테고리 · 날짜"(13px/600, `--text-subtle`). hover·초점 줄은 `--surface` 면.
- 입력칸에서 ↓ 로 결과로 내려가고, 결과 안에서 ↑↓ 로 움직인다. Esc 버튼·Esc 키·바깥 배경을 누르면 닫힌다.
- 반경 `--radius-lg`, 그림자 `--shadow-md` (사이트에서 그림자를 쓰는 두 곳 중 하나).

## 히어로 — `src/components/Hero.astro`

페이지 맨 위의 가운데 정렬 띠. 뒤로 **에버그린 점**이 떠다닌다.

```plaintext
┌────────────────────────────────────────────────────┐  배경: --bg → --bg-2 세로 그라데이션
│   ·      .        ·            .      ·      .     │  점: 에버그린 6단계 무작위
│        .       ( 둥근 이미지 100px )      .         │
│   .                 제목 20/800           ·    .   │  최대 폭 360px, 가운데
│      ·          [슬롯: 링크 아이콘]    .           │
└────────────────────────────────────────────────────┘
 위아래 여백 48/64 → 태블릿 36/48 → 모바일 30/40
```

- **이미지**: 100px 원, `--hairline` 테두리, 튀어오르며 나타난다(pop). 이미지를 안 주면 에버그린 그라데이션 **구슬**을 대신 띄운다(404, 색은 [`404.md`](./404.md#구성-요소)).
- **제목**: 단어마다 0.08s 간격으로 떠오른다. 기본은 `<h1>`. 홈·카테고리는 사이트 이름이 h1 이 아니게 `<p>` 로 쓴다(`headingLevel="p"`).
- **슬롯**: 제목 바로 아래 붙는 내용. 홈·카테고리는 링크 아이콘을 넣는다.
- **점(파티클)** — 캔버스
  - 개수 `min(90, 면적/7000)`, 반지름 0.5–1.7px, 투명도 0.25–0.85, 느리게 떠다님.
  - 색은 점마다 **에버그린 6단계 중 하나를 무작위로**. CSS 변수 `--dot-1..6` 이 라이트/다크 값을 바꿔 끼우고, 스크립트는 테마가 바뀔 때만 다시 읽는다.
  - 배경은 무채색 그대로. **점만** 초록이다.
  - 화면 밖이면 멈추고, 움직임 줄이기 설정이면 한 번만 그린다.

### ProfileHero — `src/components/ProfileHero.astro`

홈·카테고리가 쓰는 히어로. `Hero` + 프로필 그림(`avatarSrc`) + 모토 "Deserve what you want." + 회색 링크 아이콘(`SocialLinks muted`).

## 링크 아이콘 — `src/components/SocialLinks.astro`

GitHub · LinkedIn · 메일. 30px 원 안에 18px 아이콘, 간격 8px.

- 기본은 `--text` 색, `muted` 면 `--text-faint` (히어로·소개 카드).
- **메일 아이콘**은 `mailto:` 를 열면서 **주소를 복사**하고 "✓ 주소"를 2.4초 띄운다. 메일 앱이 없는 사람도 주소를 가져갈 수 있게.
- 복사 알림 위치 `toast`: `center`(아래 가운데) · `start`(아래 왼쪽) · `end`(위 오른쪽).
- 링크 값은 `src/i18n/ui.ts` 의 `social`.

## 이미지 확대 — `BaseLayout.astro` + `global.css .lightbox`

글 본문 이미지(`.prose img`)와 커버(`.post-cover`)를 누르면 화면 가득(95vw × 90vh, 비율 유지) 띄운다.
배경 `rgba(0,0,0,.85)`, 오른쪽 위 닫기 버튼. 배경·닫기·Esc 로 닫힌다. 커서는 확대/축소 돋보기.

## 규칙

- 🔴 **헤더 메뉴는 세 개(홈·소개·태그)다.** 늘리면 모바일 패널·푸터 링크도 같이 고친다.
- 🔴 헤더 도구 버튼은 `.icon-btn` 한 모양만 쓴다 (32px 원).
- 히어로 제목은 짧게. 최대 폭 360px 에서 두 줄 안에 끝나게 쓴다.
- 히어로 점 색을 바꾸면 `--dot-1..6` 만 고친다. 스크립트에 색을 쓰지 않는다.
- 그림자는 검색창·맨 위로 버튼에만 있다. 새 요소에 그림자를 주지 않는다.
