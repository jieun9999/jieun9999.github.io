# shell — 여러 페이지가 같이 쓰는 틀

페이지가 아니라, 페이지들을 감싸거나 여러 페이지에 들어가는 부분이다.
토큰은 [`foundations.md`](./foundations.md) 참고.

## 페이지 뼈대 — `src/layouts/BaseLayout.astro`

모든 페이지가 이 순서로 그려진다.

```plaintext
BaseHead   메타·폰트·테마 결정 스크립트 (화면엔 안 보임)
Header     로고 · 메뉴 · 도구
<main>     ← 페이지 내용
Footer     로고 · 링크 · 아이콘 / 태그라인 · 저작권
Lightbox   본문 이미지 클릭 확대 (평소엔 숨김)
```

## 어느 페이지가 무엇을 쓰나

| | 헤더·푸터 | 히어로 | 히어로 아래 링크 아이콘 | 맨 위로 | 검색창 |
| --- | --- | --- | --- | --- | --- |
| 홈 | ✓ | ✓ (ProfileHero) | ✓ | ✓ | ✓ |
| 카테고리 | ✓ | ✓ (ProfileHero) | ✓ | ✓ | ✓ |
| 글 상세 | ✓ | – | – | ✓ | ✓ |
| 태그 목록 | ✓ | ✓ (plain — 사진 없이 큰 제목) | – | – | ✓ |
| 태그별 글 | ✓ | ✓ (plain) | – | ✓ | ✓ |
| 소개 | ✓ | – (카드 뒤에 점 바탕) | (카드 안에) | – | ✓ |
| 404 | ✓ | ✓ (구슬) | – | – | ✓ |

**점과 사진** — 떠다니는 에버그린 점은 **헤더 메뉴 세 페이지(홈·소개·태그)에 모두** 깔고, 모두 헤더 뒤까지 올린다.
메뉴를 오가도 바탕이 끊기지 않게. 프로필 사진은 **'나'를 말하는 페이지(홈·카테고리·소개)에만** 둔다 —
태그 쪽 히어로에 사진을 두면 사진과 제목("태그")이 서로 이어지지 않는다 (2026-09-19).

## 헤더 — `src/components/Header.astro`

```plaintext
데스크톱 (100px, ≥1200) · 태블릿 (80px)
┌────────────────────────────────────────────────────────────────┐
│ 홈   소개   태그               Jieun                 🔍  EN  ☾ │
│      ‾‾‾‾                                                      │
└────────────────────────────────────────────────────────────────┘
  1fr (왼쪽 정렬)          auto (가운데)           1fr (오른쪽 정렬)

모바일 (60px, ≤809)
┌──────────────────────────────────┐
│ ☰            Jieun          🔍 ☾ │
└──────────────────────────────────┘

홈·카테고리 — 가운데 로고를 비우고 히어로의 큰 이름이 로고 노릇을 한다
┌────────────────────────────────────────────────────────────────┐
│ 홈   소개   태그            ┌──────┐                 🔍  EN  ☾ │ ← 사진 윗선 = 버튼 윗선
│                             │ 사진 │                           │
└─────────────────────────────│      │───────────────────────────┘
                              └──────┘
                               Jieun
```

- **배치**: 메뉴 왼쪽 · 로고 가운데 · 도구 오른쪽. 양옆 칸이 `1fr` 로 같은 폭이라 로고가 화면 정가운데에 서고,
  아래 히어로와 한 세로축에 놓인다. 모바일도 칸 셋을 그대로 써서 로고가 가운데에 남는다.
- **높이** `--header-h`: 데스크톱 100px(위에 붙지 않으니 메뉴가 천장에 붙어 보이지 않게 넉넉히) · 태블릿 80px · 모바일 60px.
- **로고**: 워드마크 하나(`BrandWordmark.astro`) — "Jieun" 36px(모바일 28px)/900. 아이콘은 따로 두지 않는다.
  - **홈·카테고리에선 숨긴다.** 히어로의 큰 이름(`ProfileHero`, `data-hero-name`)이 로고 노릇을 하므로 "Jieun" 이 두 번 서지 않게.
    위에 붙는 폭(≤1199)에서 스크롤해 그 이름이 헤더 밑으로 들어가면 `data-brand-shown` 이 붙고 로고가 0.2s 에 나타난다.
  - J 는 파비콘과 같은 기하 J(줄기 + 1/4원 + 반원)에 잎맥선 6개를 그은 SVG. 다크에선 민트 J + 초록 잎맥,
    라이트에선 민트가 흰 바탕에 묻히므로 뒤집어서 에버그린 J + 민트 잎맥으로 그린다(파비콘도 같은 규칙).
  - "ieun" 은 진짜 텍스트에 에버그린 세로 그라데이션을 `background-clip: text` 로 입힌다. 가운데 스톱이 `--accent`.
  - 화면엔 J 가 그림이라 스크린리더용으로 `sr-only` "Jieun" 을 따로 둔다.
  - 파비콘(`public/favicon.svg`)은 **타일 없이 J 만**. 칸을 거의 채우게(높이 약 96%) 키웠다.
    브라우저 테마(`prefers-color-scheme`)를 따라 워드마크의 J 처럼 뒤집는다 — 밝은 탭 바엔 에버그린 J, 어두운 탭 바엔 민트 J.
    SVG 파비콘을 못 쓰는 곳(Safari 등)이 받는 `favicon.ico`(16·32·48)·`favicon-96x96.png` 는 색을 못 바꾸니
    밝은 탭용(에버그린 J + 민트 잎맥) 투명 PNG 다. 헤드리스 크롬으로 `favicon.svg` 를 라이트로 렌더해 만든다.
  - `apple-touch-icon`·`web-app-manifest-*` 도 2026-09-20 에 J 로 바꿨다. `npm run icons`(`scripts/gen-icons.mjs`)가
    브랜드 SVG 를 헤드리스 크롬으로 1024 에 그려 줄인다 — `npm run og` 처럼 CI 에서는 돌지 않으니 결과 PNG 를 커밋한다.
    | 파일 | 원본 | 왜 |
    | --- | --- | --- |
    | `apple-touch-icon.png` 180 | `jieun-icon-square.svg` | 아이폰 홈 화면. iOS 가 스스로 모서리를 둥글리고 **투명한 곳은 검게 채우므로** 모서리 없는 정사각을 쓴다 |
    | `web-app-manifest-192·512.png` | `jieun-icon.svg` | `purpose: any` — 플랫폼이 자르지 않으니 타일이 스스로 둥근 모서리를 갖는다. 모서리는 투명 |
    | `web-app-manifest-maskable-512.png` | `jieun-icon-square.svg` + J 0.86 축소 | `purpose: maskable` — 가운데 80% 원 밖은 잘릴 수 있어 J 를 안전권 안으로 넣었다. 배경은 꽉 채운다 |
    SNS 카드 로고는 `design/brand/jieun-icon.svg`(타일).
  - `site.webmanifest` 의 `theme_color`·`background_color` 는 `global.css` 의 라이트 `--bg`(`#ffffff`)와 같은 값이다.
    홈 화면에서 연 직후 스플래시 색이라, 배경 토큰을 바꾸면 여기도 맞춘다.
- **메뉴**: 홈 · 소개 · 태그, 16px/600, 간격 16px.
  - 현재 메뉴는 **초록 글자 + 2px 초록 밑줄**(글자 아래 6px). 글자색만으론 검정과 구분이 잘 안 돼서 밑줄을 넣었다.
  - hover 하면 같은 밑줄이 가운데서 펼쳐진다.
  - "홈"은 `/[lang]/`, `/category/…`, `/blog/…` 에서 모두 현재 메뉴다. "태그"는 `/tags/` 와 `/tag/…` 둘 다.
- **도구**: 검색 · 언어 · 테마 순. 모두 `.icon-btn` — 32px 원, 면은 `--surface-2` 70%.
  - 언어 버튼은 **다른 언어의 코드**를 보여준다 (한국어 페이지면 `EN`). 번역이 있으면 번역 글로, 없으면 그 언어 홈으로 간다.
  - 테마 버튼은 라이트에서 달, 다크에서 해를 보여준다.
- **위치**: 데스크톱에서는 스크롤과 함께 올라가고, **1199px 이하에서는 위에 붙는다**(sticky).
- **배경**: 보통은 `--bg`. **홈·카테고리·소개·태그에선 비운다** — 히어로(소개는 점 바탕)가 헤더 뒤까지 올라와(`Hero snug`, 소개 `.field`) 점이 메뉴 뒤에서도 떠다닌다.
  위에 붙는 폭(≤1199)에선 `data-solid` 가 붙거나 모바일 메뉴를 열면 `--bg` 로 다시 칠한다(0.2s).
  `data-solid` 는 보통 스크롤하자마자 붙지만, 히어로에 큰 이름이 있으면 **이름이 헤더 밑으로 들어간 뒤에** 붙는다 —
  사진이 헤더 줄에 걸쳐 있어서 일찍 칠하면 사진 윗부분이 잘린다.
  헤더는 `body:has([data-under-header])` 로 이 페이지들을 알아본다.
- **클릭**: 비워둔 헤더 줄에 사진 윗부분이 걸치므로, 칠하기 전에는 헤더가 메뉴·로고·도구에서만 클릭을 받는다(`pointer-events`).
- **모바일(≤809)**: 메뉴와 언어 버튼이 사라지고 **메뉴가 있던 왼쪽에** 햄버거(☰)가 생긴다. 오른쪽엔 검색 · 테마만 남는다.
  - 햄버거를 누르면 헤더 아래가 전부 메뉴 패널로 덮인다. 링크가 세로로 서고, 선 아래 "View in English" / "한국어로 보기" 글자 링크.
  - 열리면 본문 스크롤이 잠긴다. Esc 로 닫히고, 링크를 누르거나 창이 810px 이상으로 넓어지면 닫힌다.
  - 🔴 **스크롤 잠금은 `<html>` 에 건다 — `<body>` 에 걸면 먹지 않는다.** `global.css` 가
    `html { overflow-x: clip }` 을 두고 있어서, 루트의 overflow 가 `visible` 이 아니게 된다.
    그러면 브라우저가 `<body>` 의 overflow 를 뷰포트로 넘겨주지 않는다(CSS Overflow §"viewport propagation").
    `body.style.overflow = 'hidden'` 은 조용히 무시되고 뒤 배경이 그대로 스크롤된다 — 빌드도 콘솔도 멀쩡하다.
    같은 이유로 **라이트박스(`BaseLayout.astro`)도 `<html>` 에 건다.** 새로 덮개를 만들 때도 마찬가지다.

## 히어로 — `src/components/Hero.astro`

페이지 맨 위의 가운데 정렬 띠. 뒤로 **에버그린 점**이 떠다닌다.

```plaintext
┌────────────────────────────────────────────────────┐  배경: --bg → --bg-2 세로 그라데이션
│   ·      .        ·            .      ·      .     │  점: 에버그린 6단계 무작위
│        .       ( 둥근 이미지 100px )      .         │
│   .                 제목 20/800           ·    .   │  최대 폭 360px, 가운데
│      ·          [슬롯: 링크 아이콘]    .           │
└────────────────────────────────────────────────────┘
 위아래 여백 48/64 → 태블릿 36/48 → 모바일 30/40   (snug 면 헤더 뒤로 올라가고 위 여백 = 헤더 높이)

name 슬롯이 있으면 (홈·카테고리)
                      ( 사진 120 )          ← 96 (모바일)
                         Jieun              ← 이름 — 넣는 쪽이 크기를 정한다
                Deserve what you want.      ← 18/600 --text-subtle (모바일 16)
                       ⌂   in   ✉

plain 이면 (태그 목록·태그별 글) — 사진·구슬 없음
                         태그               ← 28–38/900, 소개 인사말과 같은 크기
                  태그 87개 · 글 20개        ← 슬롯, 16/600 --text-subtle
```

- **이미지**: 100px 원, `--hairline` 테두리, 튀어오르며 나타난다(GSAP `POP`). 이미지를 안 주면 에버그린 그라데이션 **구슬**을 대신 띄운다(404, 색은 [`404.md`](./404.md#구성-요소)).
- **제목**: 단어마다 0.07s 간격으로 떠오른다(0.25s 부터, 아래 20px). 기본은 `<h1>`. 홈·카테고리는 사이트 이름이 h1 이 아니게 `<p>` 로 쓴다(`headingLevel="p"`).
- **슬롯**: 제목 바로 아래 붙는 내용. 홈·카테고리는 링크 아이콘을 넣는다.
- **`snug`**: 히어로가 헤더 높이(`--header-h`)만큼 위로 올라가 **헤더 뒤까지 깔리고**, 내용은 헤더 바로 밑에서 시작한다.
  점이 메뉴 뒤에서도 떠다닌다. `data-under-header` 를 달아 헤더가 배경을 비우게 한다. 홈·카테고리(`ProfileHero`)와 태그 목록·태그별 글이 쓴다.
- **`plain`**: 사진·구슬 없이 제목만 크게 — `clamp(28px, 3.4vw, 38px)`/900(소개 인사말과 같은 값), 최대 폭 없음.
  슬롯은 16px/600 `--text-subtle` 한 줄 설명. `snug` 와 같이 쓰면 위 여백은 헤더 높이 + 24px. 태그 목록·태그별 글이 쓴다.
- **`name` 슬롯**: 사진 → **이름** → 한 줄 소개 배치로 바뀐다(`.has-name`). 이름이 주인공이라 사진은 120px(모바일 96)로 키우고,
  제목은 18px/600 `--text-subtle`(모바일 16)로 낮춰 이름 밑 6px 정도에 붙인다. 사진 → 이름 16px, 이름은 0.15s 에 떠오른다.
  - `snug` 와 같이 쓰면 사진을 헤더 줄까지 올려 **사진 윗선을 헤더 버튼(32px 원) 윗선에 맞춘다** —
    위 여백 `(--header-h − 32px) / 2`. 모바일은 헤더가 얇은 막대라 그 밑(`--header-h`)에서 시작한다.
- **들어올 때 (GSAP)**: 점이 1.6s 동안 번지고(0s) → 사진·구슬이 튀어오르고(0.05s) → 이름(0.15s) → 제목 단어(0.25s 부터 0.07s 간격)
  → 슬롯(제목이 끝나기 0.55s 전). 없는 요소는 건너뛴다. 공용 약속은 [`foundations.md`](./foundations.md#들어올-때-모션--gsap-공용-약속-srclibmotionts).
- **`imageHref`**: 사진을 링크로 감싼다(홈 히어로 → 홈). 바로 밑 이름 링크와 같은 곳이라 `aria-hidden` + `tabindex="-1"` 로
  키보드·스크린리더에선 뺀다.
- **점(파티클)** — `src/components/Particles.astro` 의 캔버스. 소개 페이지 카드 뒤에도 같은 컴포넌트를 깐다.
  - 개수 `min(상한, 면적/7000)`, 반지름 0.5–1.7px, 투명도 0.25–0.85, 느리게 떠다님.
    상한은 기본 90. 히어로 띠보다 훨씬 넓은 곳은 `max` 로 올려 밀도를 맞춘다(소개 200).
  - 색은 점마다 **에버그린 6단계 중 하나를 무작위로**. CSS 변수 `--dot-1..6` 이 라이트/다크 값을 바꿔 끼우고, 스크립트는 테마가 바뀔 때만 다시 읽는다.
  - 배경은 무채색 그대로. **점만** 초록이다.
  - 화면 밖이면 멈추고, 움직임 줄이기 설정이면 한 번만 그린다.

### ProfileHero — `src/components/ProfileHero.astro`

홈·카테고리가 쓰는 히어로. `Hero snug` + 프로필 그림(`avatarSrc`, 누르면 홈) + **큰 이름**(name 슬롯) + 모토 "Deserve what you want." + 회색 링크 아이콘(`SocialLinks muted`).

- 이름은 헤더와 같은 워드마크(`BrandWordmark`)를 48px(모바일 40)로, 홈 링크로 감싼다. 뒤에 점은 찍지 않는다.
- 홈에선 이름이 **보이는 `<h1>`** 이다(`nameHeading`). 카테고리는 카테고리 이름이 숨긴 `<h1>` 이라 이름은 `<p>`.
- 이름에 `data-hero-name` 을 달아 헤더가 자기 로고를 숨기게 한다.

## 링크 아이콘 — `src/components/SocialLinks.astro`

GitHub · LinkedIn · 메일. 30px 원 안에 18px 아이콘, 간격 8px.

- 기본은 `--text` 색, `muted` 면 `--text-faint` (히어로·소개 카드).
- **메일 아이콘**은 `mailto:` 를 열면서 **주소를 복사**하고 "✓ 주소"를 2.4초 띄운다. 메일 앱이 없는 사람도 주소를 가져갈 수 있게.
- 복사 알림 위치 `toast`: `center`(아래 가운데) · `start`(아래 왼쪽) · `end`(위 오른쪽).
- 링크 값은 `src/i18n/ui.ts` 의 `social`.

## 맨 위로 — `src/components/BackToTop.astro`

600px 넘게 내려가면 오른쪽 아래(24px)에 뜨는 48px 원 버튼. `--bg` 면 + `--border` 테두리 + `--shadow-md`. hover 시 화살표가 초록.
긴 목록·긴 글이 있는 페이지에서 쓴다: 홈·카테고리·태그별 글·글 상세.

- **모바일 메뉴가 열려 있으면 숨는다.** 버튼은 `z-index: 55`, 메뉴 패널은 헤더(`z-index: 50`) 안에 있어서

  600px 아래로 내려간 뒤에 메뉴를 열어야 보이는 조합이라 눈에 잘 띄지 않는다 (2026-09-23).

## 규칙

- 🔴 **헤더 메뉴는 세 개(홈·소개·태그)다.** 늘리면 모바일 패널·푸터 링크도 같이 고친다.
- 🔴 헤더 도구 버튼과 햄버거는 `.icon-btn` 한 모양만 쓴다 (32px 원).
- 히어로 제목은 짧게. 최대 폭 360px 에서 두 줄 안에 끝나게 쓴다.
- 히어로 점 색을 바꾸면 `Particles.astro` 의 `--dot-1..6` 만 고친다. 스크립트에 색을 쓰지 않는다.
- 🔴 태그 쪽 히어로(`plain`)에 프로필 사진을 다시 넣지 않는다. 사진은 홈·카테고리·소개에만 둔다.
- 그림자는 검색창·맨 위로 버튼에만 있다. 새 요소에 그림자를 주지 않는다.
