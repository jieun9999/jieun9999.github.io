## 이 페이지가 하는 일

블로그에 처음 온 사람이 **누가 쓰는 블로그인지** 한 번에 보고(히어로), **전체 글을 최신순으로 훑는** 곳이다.
링크드인·검색에서 글 하나로 들어온 사람이 "다른 글"을 찾을 때도 여기로 온다.

## 구성 요소

### 히어로 — `ProfileHero`

[`shell.md`](./shell.md#profilehero--srccomponentsprofileheroastro) 참고. 사진 밑에 사이트 이름 "Jieun" 이 워드마크로 크게 서고(보이는 `<h1>`), 모토가 그 밑 한 줄 소개로 온다.
헤더 가운데 로고는 이 이름과 겹치지 않게 숨긴다.

### 카테고리 칩 — `src/components/ArticleBrowser.astro`

- 맨 앞 "전체 / All" + **글이 있는 카테고리만**, 글 많은 순.
- 높이 34px 알약, 12px/800 대문자, 자간 0.08em. 뒤에 개수 11px (투명도 0.55).
- 보통 `--surface` 면 `--text-muted` 글자, hover `--surface-2`. **선택된 칩은 `--accent-bg` 면 + `--accent-fg` 글자.**
- 칩은 **필터 버튼이 아니라 링크**다. 누르면 [`/category/<id>/`](./category.md) 로 간다.

### 글 목록 — `src/components/PostList.astro`

- 위에 `.eyebrow` 라벨: "All Articles" / "전체 글".
- 글 사이 간격 72px (태블릿 56, 모바일 44) — 글 안의 부제↔태그 빈 공간(대개 78px)과 비슷하게 둬야 태그가 다음 글에 붙어 보이지 않는다. 48px 은 좁았다.
- **8개씩** 보여주고 "더 보기 / Load More" 로 8개씩 더 편다. 버튼: 40px 알약, `--surface`, 12px/800 대문자.
  - 새로 펼친 첫 글 제목으로 키보드 초점을 옮긴다.
  - JS 가 없으면 숨기지 않고 전부 보여주고, 버튼도 안 그린다 (`html.js` 가 있을 때만 숨김).
- 순서: 최신순. 같은 날이면 시리즈 뒤 편이 위.

### 글 한 줄 — `src/components/PostRow.astro`

- 카드로 묶지 않는다(면·테두리 없음). 왼쪽 이미지 45% : 오른쪽 글, 간격 40px. **글 칸은 이미지 높이만큼 늘어난다** — 윗줄은 이미지 윗선, 태그는 이미지 아랫선에 붙어 줄마다 같은 자리에 온다.
- 이미지: 목록 프레임은 16:9, 반경 `--radius`, 위에 1px `--border` 선을 얹는다. 기본은 `cover`로 채우며 hover 시 1.03배 확대(0.4s)한다. 도식·스크린샷은 글의 `coverFit: contain`으로 전체를 표시하고 확대하지 않는다. `coverBackground: light | dark`로 원본에 맞는 여백 색을 지정한다. 상세 이미지에는 적용하지 않는다.
  - 커버가 없으면 `--surface` 면에 **제목 첫 글자**를 48px/800 초록으로.
- 글: 윗줄(왼쪽 카테고리, 오른쪽 날짜) → 제목(h3) 22px/800 (위 16px) → 한 줄 부제 16px/500 `--text-muted` (위 8px) → 태그 (맨 아래, 최소 위 20px).
  - **글쓴이 프로필은 목록에서 뺀다.** 글쓴이가 한 명이라 줄마다 반복할 정보가 아니다. 글 상세의 `PostMeta` 는 그대로다.
  - 윗줄은 옅게: 카테고리 12px/800 대문자 `--text-subtle`(링크, hover `--text`), 날짜 13px/600 `--text-faint` `YYYY-MM-DD`. 눈이 제목·부제로 먼저 가게 한다.
  - 부제는 frontmatter `subtitle` — 제목을 받쳐 주는 짧은 한 줄(한글 30자, 영어 60자 안팎). 없으면 `description` 을 대신 쓴다. 어느 쪽이든 **한 줄에서 자른다**(말줄임).
  - 태그는 앞에서 **3개만** `.tag` 알약(`#tag`)으로, 각각 태그 페이지 링크.
- 이미지·부제도 글로 가는 링크지만 탭 순서에서는 뺀다(`tabindex="-1"`). 키보드로는 카테고리 → 제목 → 태그 순으로 멈춘다.

## 다크 모드

토큰만 바뀐다. 선택된 칩은 **밝은 초록 면 + 검은 글자**로 뒤집힌다. 히어로 점은 다크용 6단계로 바뀐다.

## 한/영 차이

- 라벨·버튼 글자만 바뀐다 (`src/i18n/ui.ts`): "All Articles / 전체 글", "Load More / 더 보기", "All / 전체".
- **카테고리 이름은 두 언어 모두 영어**다 (Systems, Scaling …). 한국어 페이지에서도 번역하지 않는다.
- 목록 한 줄의 날짜는 두 언어 모두 `2026-09-18`. (글 상세 메타 줄은 언어별 `September 18, 2026` / `2026년 9월 18일`.)
- 부제(`subtitle`)는 언어별 파일에 각각 쓴다.
- 글 목록은 그 언어로 쓴 글만 나온다.

## 규칙

- 🔴 **카테고리 칩은 링크로 둔다.** 화면 안에서만 거르는 필터로 바꾸지 않는다 — 카테고리 URL 이 공유·검색 대상이다.
- 🔴 모토("Deserve what you want.")는 `<p>` 다. 이 페이지의 `<h1>` 은 히어로의 이름 "Jieun" 이다.
- 카테고리 글자는 대문자 유지. 태그(`#tag`)와 모양을 섞지 않는다 — 카테고리는 대문자(필터 영역은 칩, 글 한 줄에선 면 없는 글자), 태그는 원래 글자 알약.
- 목록 한 줄의 모양은 `PostRow` 하나다. 홈만 다른 카드 모양을 만들지 않는다.
- 🔴 **목록에 글쓴이 프로필(아바타·이름)을 다시 넣지 않는다.** 글쓴이가 한 명이라 줄마다 반복하면 제목·부제에서 눈을 뺏는다.
- 🔴 **부제는 한 줄.** 두 줄짜리 요약을 목록에 풀어 쓰지 않는다 — 길면 안 읽힌다. 새 글엔 `subtitle` 을 쓴다(한글 30자·영어 60자 안팎, 제목을 반복하지 말고 숫자·결론을 짚는다).
- 태그는 목록에 **3개까지**. 대표 태그를 frontmatter 앞에 둔다.
- 새 커버는 **16:9**(예: 1672×941)를 권장한다. 다른 비율의 도식·스크린샷을 보존하려면 `coverFit: contain`을 지정한다. 세로 이미지는 전체가 보이더라도 작아지므로 목록용 가로 썸네일을 별도로 준비하면 읽기 쉽다. 공통 PostRow를 쓰는 카테고리·태그 목록에도 같은 설정이 적용된다.
- 이미지와 글을 **카드(회색 면·테두리)로 묶지 않는다.** 테두리는 이미지에만 두른다.

## 알아둘 것

- 예전 홈의 `ProfileCard`·`PostCard`·`TagsPanel`·`CategoryBar` 는 리디자인(`cc0857d`) 때 지웠다. 프로필 카드(사진·이름·한 줄 소개·글 수·링크)는 히어로와 글 사이드바 `ProfileWidget` 으로 옮겨갔다.
- `PostRow` 는 `headingLevel="h2"` 로 대표 글 한 줄도 그릴 수 있게 만들어져 있지만, 지금은 대표 글 영역이 없다.
- 목록 한 줄은 2026-09 에 올리브영 테크 블로그 목록을 참고해 다시 짰다(`design/post-header-meta` 브랜치). 그때 해 본 것들:
  - 회색 패널 카드(이미지+글을 `--surface` 면 한 장으로)와 전체 테두리 카드 — 둘 다 목록이 무거워 보여 뺐다.
  - 이미지 비율 1.5 — 16:9 커버의 좌우, 특히 다이어그램 글자가 잘려서 16:9 로 돌아왔다.
  - 폭 1200 → 1040 — 글 칸이 좁아져 제목이 두 줄 덩어리로 접히고, 글 상세 본문도 한 줄 40자 안팎이 된다. 올리브영 목록 폭은 1020.
- 폭을 1040 으로 줄이면서 태블릿 기준점도 1199 → 1071px(= 1040 + 여백 16×2 − 1)로 내렸다. 예전 값이면 창 폭 1072–1199 에서 콘텐츠 폭은 그대로인데 이미지가 1040 폭으로 위에 쌓였다.
