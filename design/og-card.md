# og-card — SNS 공유 카드

사이트 안의 페이지가 아니라, **링크드인·카카오톡 등에 링크를 붙였을 때 뜨는 이미지**다.
사람들이 글보다 먼저 보는 화면이라 페이지처럼 관리한다. 운영 규칙은 CLAUDE.md "SNS 공유 카드"가 원본이다.

## 한눈에

| | |
| --- | --- |
| 결과물 | 글별 `public/og/<lang>/<slug>.jpg`, 기본 배너 `public/og-default-v5.jpg` |
| 크기 | 1200 × 630 (2배로 그린 뒤 줄여서 글자를 또렷하게) |
| 템플릿 | `scripts/og-card.html` |
| 생성기 | `scripts/gen-og.mjs` (`npm run og`, 템플릿을 고쳤으면 `npm run og -- --force`) |
| 렌더링 | 로컬 크롬 headless — CI 에선 안 돈다. 결과 JPG 를 커밋한다 |
| 쓰는 곳 | 글 상세의 `og:image`. 파일이 없으면 기본 배너로 폴백 (`BaseHead.astro`) |

## 이 화면이 하는 일

링크 미리보기 한 장으로 **무슨 글인지, 누구 블로그인지**를 알린다. 제목이 잘리지 않고 다 보이는 게 가장 중요하다.

## 구성 요소

| 요소 | 모양 |
| --- | --- |
| 바탕 | 사이트 히어로와 같은 `--bg → --bg-2` 세로 그라데이션 + 점 110개. 색은 히어로와 같은 **6단계(`Particles.astro` 의 다크 `--dot-1..6`)** 에서 점마다 하나씩, 반지름 0.7–2.1px(피드에서 절반쯤으로 줄어 보여 히어로보다 조금 크게), 투명도 0.25–0.85. 배치·색은 **제목에서 뽑은 시드**로 정해 다시 만들어도 같은 그림이 나온다 |
| 카드 | 사방 44px 안쪽, 반경 32px, `--border` 1px, `--bg` 검은 면, 안쪽 52/60/44 |
| 로고 | 타일 아이콘 `design/brand/jieun-icon.svg` 52px (에버그린 둥근 타일 + 민트 J + 잎맥). 타일이 스스로 모서리를 갖고 있어 자르지 않는다. 예전엔 파비콘을 그대로 썼는데, 파비콘이 타일을 뺀 뒤(2026-09-19) 같은 그림인 타일 원본으로 옮겼다 — 카드 모양은 그대로다 |
| 도메인 | "jieun.dev" 28/800 + **초록 밑줄 3px** (헤더 현재 메뉴와 같은 표시) |
| 배너 이름 | 헤더·푸터와 같은 워드마크(`BrandWordmark.astro`)의 **다크 판**을 SVG + 글자로 옮겨 그린다: J 는 민트 세로 그라데이션(`#e2f6ea → #bcebd1 → #93d6b1`) + 에버그린 잎맥(`#307252`, 45%), "ieun" 은 밝은 초록(`#9ce4bd → #72be96 → #4b916e`)을 글자에만 칠한다. 84px/900 |
| 카테고리 | `--surface` 칩, 18/800 대문자, 자간 0.08em |
| 시리즈 | 제목 앞 `[시리즈 N편]` 대괄호를 떼어 `--accent-soft` 면 + 초록 글자 알약으로 |
| 제목 | 800, 줄간격 1.24, 자간 -0.015em, **어절 단위 줄바꿈**. 62px 에서 시작해 남은 세로에 들어갈 때까지 줄인다 (자르지 않는다) |
| 아래 줄 | 위 `--border` 선, 아바타 38px + "**Jieun** · Deserve what you want." 22px, 오른쪽 발행 **연.월**(`2026.05`) 700 |
| 글꼴 | Nunito + Pretendard — 사이트와 같은 조합 (woff2 를 임시 폴더로 복사해 쓴다) |
| 아바타 | `public/avatar-illustration.jpg` (홈과 같은 그림) |

## 테마 · 한/영 차이

- **카드는 언제나 다크 한 벌이다.** 미리보기 화면의 테마를 알 수 없으니 한 벌만 쓴다.
  2026-09-20 에 라이트 → 다크로 옮겼다 — 피드에서 흰 카드가 너무 튀었다.
- ⚠ 카드 색과 **사이트 테마는 무관하다.** 사이트는 `BaseHead.astro` 가 OS 설정과 KST 시각으로
  라이트/다크를 정한다. 카드를 다크로 바꿨다고 사이트가 다크로 고정되는 게 아니다.
- 언어별로 따로 만든다. `/ko/` 글을 공유하면 한글 제목 카드가 뜬다.

## 규칙

- 🔴 **새 글을 쓰면 `npm run og` 를 돌리고 결과 JPG 를 같이 커밋한다.** 안 하면 링크드인에 제목 없는 기본 배너가 뜬다.
- 🔴 **배너 디자인을 바꾸면 파일명 버전을 올린다** (`og-default-v6.jpg` …) 그리고 `BaseHead.astro` 와 `src/pages/index.astro` 의 기본값도 바꾼다. 링크드인·카톡이 이미지를 URL 단위로 캐시한다.
- 🔴 예전 배너(`og-default-v2.jpg` … `v5.jpg`)와 `public/og/*.jpg`(언어 폴더 밖 8장)는 **지우지 않는다.** 이미 공유된 링크가 참조한다.
- 🔴 템플릿 색은 `global.css` 다크 팔레트(`html.dark`)와 **같은 값**이어야 한다. 사이트 색을 바꾸면 템플릿도 맞추고 `--force` 로 다시 만든다.
- 제목은 줄여서라도 **전부** 보여준다. `line-clamp` 로 자르지 않는다.

## 알아둘 것

- **2026-09-20 에 다크로 옮기고 전부 다시 만들었다** (배너 `v5` → `v6`, 글별 카드 40장).
  - 팔레트: `global.css` 라이트 → 다크(`html.dark`). 점도 다크 6단계로.
  - 워드마크: 에버그린 J → 민트 J + 에버그린 잎맥 (헤더의 다크 판과 같다).
  - **`jieun.dev · Engineering Blog` 초록 알약을 뺐다.** 바로 위에 워드마크와 태그라인이
    있는데 도메인을 또 말하는 게 군더더기였다.
  - 글별 카드는 경로가 고정(`public/og/<lang>/<slug>.jpg`)이라 같은 URL 에서 그림만 바뀐다.
    이미 공유된 글 링크의 카드도 함께 바뀐다 — 배너와 달리 버전을 올릴 수 없는 자리다.
- **2026-09-19 브랜드 교체와 함께 전부 다시 만들었다** (배너 `v4` → `v5`).
  - 점: `#18181b` 회색 → 사이트 히어로와 같은 에버그린.
  - 로고: 앱 아이콘(`web-app-manifest-512x512.png`, 나무)을 잘라 쓰던 것 → 파비콘 타일.
  - 배너 이름: 검은 "Jieun" 76/800 → 워드마크.
- 같은 날 **`%` 가 든 제목의 카드가 통째로 비던 버그**를 고쳤다. 템플릿이 URLSearchParams 로 이미 풀린 값을
  `decodeURIComponent` 로 한 번 더 풀어서 `88%에서` 같은 글자가 깨진 이스케이프로 읽혔다
  (`switching-llm-accounts-…` 한·영 두 장이 처음부터 빈 카드였다).
- 이제 카드가 앱 아이콘을 쓰지 않으므로, `apple-touch-icon`·`web-app-manifest-*` 를 새 로고로 바꿔도 카드에는 영향이 없다.
