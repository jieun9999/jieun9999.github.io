# 404 — 없는 페이지

## 한눈에

| | |
| --- | --- |
| URL | `/404` (GitHub Pages 가 없는 주소에서 `404.html` 을 보여준다) |
| 소스 | `src/pages/404.astro` |
| 컴포넌트 | `Hero`(제목 "404", 이미지 없음 → 구슬) → 안내 문장 + 홈 링크 둘 |
| 헤더 현재 메뉴 | 없음 |
| 검색 노출 | – (404 응답) |
| 페이지 제목 | "404 · Not Found", `lang="en"` |

## 이 페이지가 하는 일

잘못 들어온 사람을 **어느 언어든 홈으로 돌려보낸다.** 어느 언어 사용자인지 모르는 페이지라 한 화면에 두 언어를 같이 쓴다.

## 화면 구조

```plaintext
┌ Header ───────────────────────────────────────────────┐
├ Hero ─────────────────────────────────────────────────┤
│                 ( 에버그린 구슬 100 )                  │
│                           404               <h1>      │
├───────────────────────────────────────────────────────┤
│                                          위 48px      │
│          This page could not be found.                │  ← 16px, --text-muted, 가운데
│          페이지를 찾을 수 없습니다.                      │
│                                          24px         │
│        [ENGLISH HOME]   [한국어 홈]                    │  ← .chip 링크 둘
│                                          아래 80px    │
├ Footer ───────────────────────────────────────────────┤
```

## 구성 요소

- **히어로**: `Hero` 에 이미지를 주지 않아 **구슬**(`.hero-orb`)이 뜬다. 뒤 점은 다른 히어로와 같은 에버그린.
  - 구슬은 두 겹의 방사 그라데이션이다: 왼쪽 위(30%, 30%)에서 퍼지는 **구 몸통** + 가운데서 투명해지는 **심**.
  - 라이트: 몸통 `#e2f6ea → #bcebd1 → #93d6b1`(에버그린 타일 단계), 심 `#4b916e`. accent(`#307252`)로 하면 옅은 몸통과 섞여 가운데가 탁한 회녹색이 돼서 한 단계 밝혔다.
  - 다크: 몸통 `#4f9773 → #256648 → #195e3f`, 심 `#bcebd1`(잎맥선) — 어두운 구 안에서 빛나는 반딧불처럼.
  - 값은 `Hero.astro` 의 `--orb-*` 변수에만 있다.
- **안내 문장**: 영어 줄 + 한국어 줄 (`ui.en.notFound`, `ui.ko.notFound`), 16px, 줄간격 1.6.
- **홈 링크**: `.chip` 두 개, 간격 10px — "English home" → `/en/`, "한국어 홈" → `/ko/`. 칩이라 대문자로 보인다.

## 반응형

히어로 여백만 기준대로 줄고, 나머지는 가운데 정렬 그대로다.

## 다크 모드

토큰이 바뀌고, 구슬은 `--orb-*` 가 다크 값으로 바뀐다 (위 "구성 요소").

## 한/영 차이

없다. 한 페이지에 두 언어가 같이 있다. 헤더·푸터는 영어(`lang="en"`)로 그려진다.

## 규칙

- 🔴 안내 문장과 홈 링크는 **두 언어 모두** 둔다. 한쪽만 남기지 않는다.
- 문장은 한 줄씩 짧게. 검색창·추천 글 같은 걸 붙이지 않는다 — 여기선 홈으로 보내는 게 전부다.

## 알아둘 것

- 구슬은 원래 분홍 `#f0426b` 심 + 하늘·보라(`#8ab4f8`, `#b9a4ff`, `#e9d5ff`) 몸통이었다. 포인트가 보라였던 시절 값이라 에버그린 단계로 바꿨다 (2026-09-19). 모양(두 겹 그라데이션, 100px)은 그대로다.
