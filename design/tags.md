# tags — 태그 목록

## 한눈에

| | |
| --- | --- |
| URL | `/[lang]/tags/` |
| 소스 | `src/pages/[lang]/tags/index.astro` |
| 컴포넌트 | `Hero plain snug`(큰 제목 "Tags"/"태그" + 한 줄 요약, 사진 없음) → 태그 구름 |
| 헤더 현재 메뉴 | 태그 |
| 검색 노출 | ✓ |
| 페이지 제목 | "Tags · Jieun" / "태그 · Jieun" |

## 이 페이지가 하는 일

블로그가 **어떤 기술을 다루는지** 한눈에 보여주는 색인. 관심 있는 태그를 눌러 [태그별 글](./tag.md)로 간다.
카테고리(4개, 큰 분류)와 달리 태그는 기술 이름 단위라 수가 많다.

## 구성 요소

### 히어로

- [`shell.md`](./shell.md#히어로--srccomponentsheroastro) 의 `Hero` 를 `plain snug` 로 쓴다 — 사진 없이 큰 제목, 헤더 뒤까지. 제목이 이 페이지의 `<h1>`. 링크 아이콘은 없다.
- 제목 밑 한 줄: `태그 N개 · 글 M개` / `N tags · M posts` — 구름이 얼마나 큰지 먼저 알려준다. 글 수 표기는 `postCount`.

### 태그 구름

- `<ul>` 가운데 정렬, 최대 폭 720px, 줄바꿈, 간격 10px.
- 태그 하나 = `TagPill` (`src/components/TagPill.astro`) — `.tag` 알약을 조금 키운 것: 14px/700, 안쪽 7/12px, 간격 6px, `--surface` 면, hover `--surface-2` + `--text`.
- 같은 알약이 [태그별 글](./tag.md) 목록 라벨에도 쓰인다(링크 없이). 모양을 바꾸면 두 화면이 같이 바뀐다.
- 글자: `#` + **태그 원래 글자** (대문자로 올리지 않음) + 개수 12px/800 `--text-faint`.
- 순서: **글 많은 순**, 같으면 이름순 (`tagStats`).
- 모든 태그가 같은 크기다 (글 수로 글자 크기를 바꾸지 않는다).

## 한/영 차이

- 제목 "Tags" / "태그", 요약 줄 "87 tags · 20 posts" / "태그 87개 · 글 20개".
- 태그는 **그 언어의 글에 달린 것만** 나온다. 한/영 글의 태그가 다르면 두 페이지의 구름도 다르다.
- 태그 글자는 번역하지 않는다 (frontmatter 에 쓴 그대로).

## 규칙

- 🔴 태그는 **원래 글자 그대로** 보여준다. 긴 태그(`anti-detect`, `product-development`)를 대문자로 올리면 읽히지 않는다 — 대문자는 카테고리 칩만.
- 태그 구름에 크기·색 차등(워드 클라우드)을 넣지 않는다. 개수 숫자로 충분하다.
- 🔴 히어로에 프로필 사진을 다시 넣지 않는다. 사진은 '나'를 말하는 페이지(홈·소개)에만 둔다 ([`shell.md`](./shell.md#어느-페이지가-무엇을-쓰나)).

## 알아둘 것

- 히어로는 처음엔 프로필 그림 100px + 제목 20/800 이었다. 사진 밑에 "태그"가 서서 둘이 이어지지 않아, 사진을 빼고 제목을 소개 인사말 크기로 키웠다 (2026-09-19).
- 몇몇 글은 frontmatter `tags` 가 비어 있다(최근 글 다수). 그 글들은 이 구름에 안 잡힌다 — 태그를 채우면 자동으로 늘어난다.
