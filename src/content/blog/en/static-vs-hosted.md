Hosted blog platforms are convenient, but they optimize for *their* metrics, not yours. Here is why I switched to a static site.

## No database

A static site is just HTML files generated ahead of time. There is no database to back up or migrate — my posts are Markdown files in a Git repository. The repo *is* the backup.

## I control the SEO

On a hosted platform, SEO is automatic but uniform. With a static site I control every tag — including `hreflang`, which tells Google that two pages are the same article in different languages.

## I own everything

My content is plain text I can move anywhere. No lock-in.
