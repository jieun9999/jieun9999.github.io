호스팅형 블로그 플랫폼은 편하지만, *그들의* 지표에 최적화되어 있지 내 것에 맞춰져 있지 않습니다. 제가 정적 사이트로 옮긴 이유입니다.

## 데이터베이스가 없다

정적 사이트는 미리 생성해둔 HTML 파일 덩어리일 뿐입니다. 백업하거나 마이그레이션할 DB가 없어요 — 제 글은 Git 저장소 안의 마크다운 파일입니다. 저장소가 곧 백업이죠.

## SEO를 내가 통제한다

호스팅 플랫폼에서 SEO는 자동이지만 획일적입니다. 정적 사이트에서는 모든 태그를 내가 통제해요 — 두 페이지가 같은 글의 다른 언어 버전임을 구글에 알려주는 `hreflang`까지 포함해서요.

## 전부 내 소유다

제 콘텐츠는 어디로든 옮길 수 있는 순수 텍스트입니다. 종속(lock-in)이 없어요.
