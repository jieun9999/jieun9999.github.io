반갑습니다! 제 이중언어 개발 블로그의 첫 글입니다. 헤더의 **EN / KO** 토글을 누르면 같은 글을 영어로 읽을 수 있어요.

## 왜 이중언어 블로그인가

더 많은 독자를 위해 영어로 발행하지만, 저는 한국어로 더 정확하게 생각합니다. 하나만 고르는 대신, 이 블로그의 모든 글은 두 언어로 존재하고 독자가 클릭 한 번으로 고릅니다.

## 어떻게 동작하나

각 글은 마크다운 파일입니다. 영어판과 한국어판은 **같은 파일명**을 공유하고, 토글은 이를 보고 둘이 짝이라는 걸 압니다:

```
src/content/blog/
  en/hello-astro.md   ← 영어판
  ko/hello-astro.md   ← 이 글
```

이 사이트는 정적 사이트 생성기 [Astro](https://astro.build)로 만들었습니다. 보이는 모든 것은 빌드 시점에 생성된 순수 HTML이라, 데이터베이스도 관리할 서버도 없습니다.

### 코드도 보기 좋아요

문법 강조가 기본으로 동작하고, 라이트/다크 테마 모두 지원합니다:

```ts
function greet(name: string): string {
  return `안녕, ${name}!`;
}

console.log(greet('세계'));
```
