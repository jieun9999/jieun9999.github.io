## 관찰한 구성

도입 범위를 밝히고 보안 상담에서 필요한 작업을 설명한다. 자료가 흩어져 생기는 어려움을 바탕으로 플랫폼의 전체 구조와 세 사용 방식을 소개한다. 각 사용 방식에서 문제, 처리 흐름, 출력과 사람의 역할을 설명하고 사례와 피드백으로 구체화한다.

## 가져올 편집 원칙

기술 목록을 보기 전에 사용자가 하던 일을 이해하게 한다. 전체 그림 뒤에 개별 기능을 설명한다. 무엇을 제공하는지와 어디까지 책임지는지를 함께 보여준다.
