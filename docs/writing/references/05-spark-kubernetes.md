## 관찰한 구성

기존 실행 환경의 한계와 전환 이유를 설명하고 광고 데이터 파이프라인을 소개한다. 새 실행 방식의 개념에서 시스템 구성으로 내려가며, 메모리와 작업 실패 등 운영 문제를 다룬 뒤 도입 효과를 정리한다.

## 가져올 편집 원칙

데이터가 어디서 와서 어디로 가는지 먼저 보여준다. 이후 각 구성 요소가 필요한 이유와 역할을 설명한다. 운영상의 문제도 전체 구조의 어느 지점에서 생겼는지 연결한다.

## jieun.dev 적용

부하 테스트 환경, VPS 개발 환경, 외부 협업자 격리, 회의 녹음에 적합하다. 명령어와 설정을 나열하기 전에 전체 흐름에서 해당 설정의 역할을 밝힌다. 대규모 플랫폼의 구성 요소를 작은 시스템에 불필요하게 추가하지 않는다.
